# Spilling

Spilling is the process of temporarily moving data from faster storage (like RAM) to slower storage (like disk) when there is insufficient memory to hold all the data being processed. This technique is commonly used in database management systems, big data processing frameworks, and operating systems to handle large datasets that exceed available memory.

When a system runs out of memory, it "spills" some of the data to disk to free up space for new data. This can involve writing intermediate results of computations, caching data that is not immediately needed, or offloading less frequently accessed data.
